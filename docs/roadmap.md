# GlassImpact 当前进度与路线图

本路线图对应固定工况方案 A。当前已完成 **synthetic 数据处理与 UE 显示验证**；真实 COMSOL 玻璃断裂尚未求解。以下用可检查的交付物界定进度，不以图片的逼真程度替代物理验证。

## 已完成：数据与显示基线

- 独立项目目录、模块依赖说明、COMSOL GUI 建模路线及数据协议。
- 32 时刻、0–20 ms 的固定参考表面合成样例，来源明确写入 `source.json`。
- CSV 检查、不规则表面到 512×512 UV 纹理插值、全时程统一编码、两份 RGBA16F、元数据、PNG16 与独立动画预览。
- 转换器 23 项、COMSOL 文本适配器 4 项测试通过；验证损伤不可逆、方向、长度、哈希和量化误差。
- UE 5.6 C++ 编译、材质及关卡生成、指定物理时间截图通过；建立三种相机和网格显示。
- 当前装配已修正玻璃四边间隙，使用连续倒角框、密封条和统一相机构图。

证据见 [验收记录](validation.md)、[二进制核查](binary_verification.json) 和 [装配修订](composition_refinement.md)。UE 截图由指定时间定位生成，不代表持续播放性能、全部按键和特效事件已经逐项验收。

## P0：确认模块，建立弹性接触基线

**目标：在引入裂纹之前，确认载荷、接触、边界、尺度和时间设置正确。**

| 工作 | 交付物 | 通过条件 |
|---|---|---|
| 核实 COMSOL 6.3 模块 | 模块可用性记录与最终路线选择 | 实际可添加并运行所需接口，不能只依据安装目录判断 |
| 复现官方相场基准 | 模型、日志、关键曲线与官方对照 | 能复现实例的主要响应，并理解不可逆与求解设置 |
| 建立 1 m、8 mm 板与刚球接触 | 弹性基线模型、明确的球半径/质量/速度和支撑条件 | 接触发生位置与方向正确；无错误穿透和单位偏差 |
| 核对弹性动力响应 | 接触力、冲量、位移和能量时间曲线 | 量级合理，时间步足以解析接触过程；能量收支得到解释 |

刚球尺寸、初速度、玻璃断裂能和缺陷参数仍需确定或标定。不能为了得到放射状图案任意调整后将其称为物理预测；对称条件下的裂纹分支也不能预先保证。

COMSOL 操作顺序见 [建模指南](comsol_model_guide.md)。如果模块不支持推荐方案，按指南比较连续损伤、Cohesive Zone 和预定义路径，记录能力差异后再选择。

## P1：建立并验证真实断裂模型

**目标：让 UE 播放的数据有可追溯、经过检查的真实求解来源。**

| 工作 | 交付物 | 通过条件 |
|---|---|---|
| 加入断裂及材料参数 | 带参数依据和假设的模型版本 | 记录相场定义、拉压分裂、断裂能、长度尺度和残余刚度 |
| 检查不可逆与卸载 | 节点/积分点损伤时间曲线 | 卸载后无裂纹愈合；不能在 Python 用累积最大值掩盖求解问题 |
| 检查能量收支 | 动能、弹性能、断裂耗散、接触和外功曲线 | 解释误差、阻尼与数值耗散，避免只凭最终裂纹图判断 |
| 检查离散化敏感性 | 逐级加密的网格/时间步对比 | 接触力、峰值位移及损伤趋势达到事先说明的可接受变化范围 |
| 导出真实参考表面 | CSV、`source.json`、模型及导出设置记录 | 字段定义、坐标、单位和时间一致；不混合不同厚度表面 |
| 重跑转换与 UE 验证 | 独立预览、metadata、UE 相同时刻截图 | 数据校验通过，COMSOL 与 UE 的中心位置、方向、时间和位移尺度一致 |

第一次接入只替换经过验证的数据，保留 synthetic 样例作为软件回归测试。真实数据目录和来源标识必须与合成样例区分。操作见 [真实数据替换](real_data_replacement.md)。

相场变量表示弥散的裂纹指标，通常不直接等于可见裂缝宽度。材质发白、法线与折射的美术参数应独立记录；双面显示同一表面也不等于已经获得双面和厚度内部裂纹。

## P2：完善材质、交互与游戏部署

**目标：在物理数据经过验证后，提高可读性、播放稳定性和可复现性。**

| 工作 | 交付物 | 通过条件 |
|---|---|---|
| 材质与厚度表现 | 完整/早期/最终损伤的多视角对照 | 裂纹时序清楚，装配无缝隙；显示倍率和美术处理有标识 |
| 键盘与事件验收 | Play/Pause/Reset/Seek、相机、网格、阈值回调测试记录 | 暂停恢复不重复触发，复位可重播，预览 Seek 无额外音粒子副作用 |
| 补齐特效资源 | 可分配的 Niagara 粉尘与声音 | 触发位置正确、单次播放次数正确；资源来源和使用权限明确 |
| 异步读取与缓存 | 预取/环形缓存实现及对比 | 时间索引变化时无错误帧；测试磁盘和缓存边界 |
| 60 FPS 与内存测量 | 指定硬件、分辨率和画质的帧时间报告 | 测量持续播放与加载尖峰，不能以截图或编译成功代替 |
| 游戏打包 | 可安装/启动的打包产物和步骤 | 原始场数据完整随包分发，离开编辑器仍可加载与播放 |

## 本阶段边界

当前不实现多工况 B、机器学习代理模型 C、运行时 COMSOL、完整碎片分离或真实碰撞网格断裂。固定工况 A 通过物理和播放验收后，再评估多工况的参数范围、存储规模和插值误差；代理模型需要另立数据覆盖与泛化验证计划。

下一项具体工作是 **P0 的模块确认与弹性接触基线**，随后再加入断裂。截图展示完成不等于整个物理项目完成。
