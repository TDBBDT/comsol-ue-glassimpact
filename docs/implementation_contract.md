# Implementation contract v1

Independent GlassImpact project; all initial data is `synthetic`. Never label a generated crack pattern as a solved fracture.

Raw sidecar must explicitly declare `domain_topology="single_convex_plate_without_holes"`. V1 uses a Delaunay surface triangulation and does not support holes, disconnected components, or adaptive changing reference meshes. Reject those inputs rather than filling gaps silently.

Raw CSV: `time_s,node_id,x_m,y_m,z_m,u_m,v_m,w_m,sigma1_Pa,von_mises_Pa,damage,strain_energy_J_m3`. Fixed reference coordinates, same node IDs and XY triangulation at all times, one selected plate surface only (not mixed top/bottom). Z=0 reference mapping surface, x,y in [-0.5,0.5] m. Damage 0 intact / 1 damaged, nondecreasing per material point. Time sequence strictly increasing after grouping. Raw sidecar `source.json` must declare `source_kind` (`synthetic` or `comsol`), field definitions and coordinate provenance.

Processed: `metadata.json`, `state.rgba16f`, `displacement.rgba16f`, optional PNG16 damage frames / preview GIF. Two headerless little-endian IEEE float16 arrays, shape [T,H,W,4], row-major. Texture texel centers: x=-.5+(i+.5)/W; y=-.5+(j+.5)/H. Row j=0 is y minimum, upload directly (no vertical flip). UV0=(x+.5,y+.5). Saved preview can flip vertically only for presentation, explicitly labeled.

State RGBA: damage (unmodified [0,1]), globally affine-normalized sigma1, von Mises, strain energy. Displacement RGBA: globally affine-normalized local u,v,w, coverage (1 inside interpolation hull; 0 outside). Three displacement component minima/maxima held constant across every frame. Degenerate ranges encode 0 and decode minimum. All valid physical extrema stored in SI. Outside coverage -> zero damage/displacement in material; no nearest-neighbor extrapolation.

metadata fields agreed for UE: version=1, source_kind, duration_seconds, frame_count, times_seconds[], texture_resolution=[W,H], plate_size_m=[1,1], source_units="SI", ue_units="cm", state_file="state.rgba16f", displacement_file="displacement.rgba16f", displacement_min_m=[...], displacement_max_m=[...], stress1_range_Pa=[min,max], von_mises_range_Pa=[min,max], energy_range_J_m3=[min,max], max_damage_per_frame[], impact_uv=[.5,.5], coordinate_mapping="plate_local_xy_to_ue_local_xy_m_to_cm", dtype="float16", byte_order="little", channels/state_layout docs, hashes, validation results. duration_seconds=times[-1]-times[0]. Physics timeline must start at 0 for MVP.

UE loads two adjacent frames from disk only when frame index changes, transient PF_FloatRGBA textures (sRGB=false, clamp, bilinear, no mips). Dynamic material params StateA/StateB, DispA/DispB, FrameAlpha, DamageThreshold, CrackWhiteningStrength, RefractionStrength, CrackIntensity, DisplacementMin (cm vector), DisplacementSpan (cm vector). Decode/interpolate in plate LOCAL space then transform local displacement to world for WPO. Coverage gates all effects. Material sampling UV uses the above row convention. Vertex grid is tessellated fixed topology, not a four-vertex plane; 129x129 recommended. 512 texture is rendering resolution, not FE convergence.

UE independent uproject GlassImpact/unreal/GlassImpact.uproject. Plugin or module GlassImpactRuntime defines UGlassImpactDataAsset, UGlassImpactPlaybackComponent, AGlassImpactDemoActor, GameMode/HUD if useful. Demo must visibly label SYNTHETIC; start paused flat, Play/Pause/Reset, centered oblique/front/side cameras and wireframe view. Niagara/audio event can be optional assigned assets; never claim audible effects without a tested asset. Scope permits building/running installed UE5.6, no need to modify SoilBridge project. No remote publication requested for this project.
